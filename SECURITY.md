# Security Policy

SatCore Solutions toma en serio la seguridad de sus proyectos y de la información procesada por ellos.

## Reportar una vulnerabilidad

Si encuentras una posible vulnerabilidad de seguridad, evita crear un Issue público con información que pueda permitir su explotación.

Utiliza un canal privado para comunicar el problema al responsable del proyecto.

## Información recomendada

Cuando sea posible, incluye:

- descripción de la vulnerabilidad;
- pasos para reproducirla;
- impacto potencial;
- versión afectada;
- evidencia técnica;
- posible solución o mitigación.

No incluyas información personal, credenciales, tokens, claves API u otros secretos.

## Qué no hacer

No publiques:

- credenciales;
- contraseñas;
- API keys;
- tokens;
- secretos de infraestructura;
- información personal;
- información que permita acceder a sistemas sin autorización.

## Gestión de vulnerabilidades

Las vulnerabilidades reportadas serán evaluadas según:

- severidad;
- impacto;
- alcance;
- facilidad de explotación;
- versiones afectadas.

Cuando corresponda, se desarrollará una corrección y se actualizará la documentación.

## Dependencias

Las dependencias del proyecto deben mantenerse razonablemente actualizadas.

Cuando sea necesario, se revisarán vulnerabilidades conocidas mediante las herramientas correspondientes del ecosistema.

## Alcance

Esta política aplica al código y a los componentes mantenidos dentro de este repositorio.

Los servicios externos y dependencias de terceros están sujetos a sus propias políticas de seguridad.

## Contacto

Para información de contacto relacionada con seguridad, consulta los canales oficiales indicados en el README del proyecto.
